# AI disclosure

- This repository is personal work by Kwun Ho James Kong, done in personal time. It contains no
  code, data or documents from any employer, and it runs only on public data.
- Code and documentation were written with AI assistance (Anthropic's Claude, via Claude Code).
  Every line has been read and is explainable by the author; design decisions are the author's.
- Every check is deterministic; no language model takes part in a check. The research agent's
  plan and draft steps do call a language model (Anthropic's API), and every brief it produces
  names the provider and model and keeps the records the model was given, so the checks can be
  re-run without it. The table checks never call a model at all.
