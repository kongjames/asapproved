# Contributing

- **Open an issue first.** Say what you ran, on which public data, and what you expected.
- **Validation reports** go in as issues using the "Validation report" template; attach the report.
- **No patient data, no employer data.** Public datasets only (CDISC pilot via pharmaverse, openFDA,
  ClinicalTrials.gov, PubMed identifiers).
- **Small pull requests with tests.** Golden files change only with `python examples/pharma_tlf/make_example.py`
  and a note in the PR explaining why the expected output moved.
- Disclose AI assistance in your PR description, as this repository does in `AI_DISCLOSURE.md`.
